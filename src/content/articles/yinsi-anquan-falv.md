## 法律层面

### 中国大陆

《计算机信息网络国际联网管理暂行规定》要求，计算机信息网络直接进行国际联网，必须使用国家公用电信网提供的国际出入口信道；任何单位和个人不得自行建立或者使用其他信道进行国际联网。该规定第十四条写明：违反上述规定的，由公安机关责令停止联网、给予警告，可以并处 15000 元以下的罚款。网上流传的各种具体罚款数字，常把不同法规的条款混在一起，请以法规原文为准。

此外，《网络安全法》等法律对利用网络从事违法活动有明确禁止。**使用工具本身的风险，与通过工具从事的行为的风险，要分开看**：后者（如传播违法信息、诈骗、侵犯他人权益）无论用什么工具都会被追究。

另需注意：**出售、搭建、推广**代理服务的风险显著高于个人使用，以此牟利的案例曾被按非法经营罪追究刑事责任。在单位网络中使用，还要遵守单位规定；公职人员和涉密岗位另有纪律要求。

### 其他地区

不同国家和地区对 VPN 和加密通信的规定差别很大，出行前请查询当地规定。

## 隐私层面：机场能看到什么

| 数据 | 机场能否看到 |
|---|---|
| 你的真实 IP、连接时间 | 能 |
| 流量大小 | 能 |
| 访问的域名 | 通常能 |
| HTTPS 网页内容、密码 | 不能 |
| 非加密（HTTP）网页内容 | 能 |

所以：只访问 HTTPS 网站；敏感账号开启两步验证；不要把机场当成匿名工具。

## 安全层面：下载与账号

1. **客户端只从官方渠道下载**：项目的 GitHub Releases 页面或官方应用商店，不用“破解版”“汉化版”。
2. **订阅链接不要分享**：它等于账号凭证。不要发到群里，也不要提交给在线订阅转换网站。
3. **机场账号用独立密码**，并绑定常用邮箱以便找回。
4. **iOS 外区 Apple ID** 只用于下载应用，不要在上面绑定重要信息，也不要使用别人提供的共享账号登录 iCloud。

## 资金层面：跑路风险

机场大多是小团队运营，停运时有发生。降低损失的做法：

- 首次购买选月付或最短周期；
- 不在促销时购买超长周期；
- 不预充大额余额；
- 留意公告频道和续费前的稳定性。
