订阅导入失败是新手最常遇到的问题，很多“梯子连不上”其实也是导入出了问题。好消息是，绝大多数情况都能在五分钟内自己解决。下面按报错表现分类说明。如果你更喜欢一步一步点着排查，可以用 [故障排查助手](/tools/guzhang-paicha/)。

## 先理解订阅是什么

订阅链接是一个网址。客户端访问这个网址，下载到一份包含所有节点的配置。所以“导入失败”本质上是两件事之一：**下载失败**，或**下载到了但看不懂**。

## 各客户端的导入入口速查

| 客户端 | 导入位置 | 需要的订阅 |
|---|---|---|
| Clash Verge Rev | 左侧“订阅” → 粘贴链接 → 导入 | Clash 订阅 |
| ClashParty | “订阅管理” → 粘贴链接 → 导入 | Clash 订阅 |
| Shadowrocket | 右上角“+” → 类型选 Subscribe | 通用订阅或小火箭订阅 |
| v2rayN | 订阅分组 → 订阅分组设置 → 添加 | 通用订阅 |
| v2rayNG | 左侧菜单 → 订阅分组设置 → “+” | 通用订阅 |
| Hiddify / Karing | “+” 或“我的配置” → 从剪贴板添加 | 多种格式都可以 |

界面文字可能随版本略有不同。导入后记得点一次“更新订阅”，节点才会出现。

## 报错“解析失败”“invalid config”：格式不匹配

不同客户端认的格式不同：

| 客户端 | 应使用的订阅 |
|---|---|
| Clash Verge Rev、ClashParty、Clash Meta for Android | Clash 订阅（YAML） |
| v2rayN、v2rayNG | 通用订阅 / V2Ray 订阅（Base64） |
| Shadowrocket | 通用订阅，或机场提供的 Shadowrocket 专用订阅 |
| sing-box | sing-box 订阅（JSON） |
| Hiddify、Karing | 多数格式都能识别 |

在机场用户中心找对应按钮复制即可。

## 报错“超时”“下载失败”：下载不到

1. **链接不完整**：用“复制”按钮重新复制，不要手动框选。
2. **系统时间错误**：时间偏差大会导致 HTTPS 证书校验失败，开启自动校时。
3. **订阅域名被干扰**：换手机热点再试；有备用订阅地址就换备用地址。
4. **客户端“通过代理更新”设置**：首次导入时还没有可用代理，确认更新订阅不走一个不存在的代理。

## 导入成功但没有节点或全部不可用

- **套餐到期或流量用尽**：登录用户中心检查。
- **客户端太旧**：不支持 VLESS Reality、Hysteria2 等新协议，升级到最新版。
- **节点已更换**：点击“更新订阅”，旧节点会被替换。

## 一份通用自查清单

1. 订阅格式与客户端对应
2. 链接以 https:// 开头，完整无空格
3. 系统时间准确
4. 套餐有效、流量未用完
5. 客户端为最新版本
6. 关闭其他代理软件后再试
