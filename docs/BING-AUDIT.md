# Bing 深度审查（2026-10-22）

工具：`node scripts/deep-audit.mjs`（结果写入 reports/deep-audit.json）。

## 结论排序（影响从大到小）

1. **网站尚未上线**：vpntizi.blog 目前不是本站内容，抓取被 robots 拒绝；Bing 搜索 `site:vpntizi.blog` 无结果。部署到 Cloudflare Pages 并绑定域名前，任何优化都不会生效。
2. **国内版 Bing（cn.bing.com）**：翻墙类内容在国内版受合规过滤，无法通过优化解决；本站可争取的是国际版 Bing 的中文搜索。不做针对国内版的伪装（cloaking）。
3. **新域名 + 零外链**：Bing 很看重外链与站点年龄；“VPN”“梯子”“机场”这类大词短期内上首页不现实，先拿品牌长尾词（如“灵动云机场怎么样”）。注意“机场”单独搜索会被真实机场结果占据。
4. **资料来自公开整理、缺少第一手实测**：30 家资料非官网核对，没有本站实测截图；这是内容质量里最大的短板（Bing 指南对“联盟站缺少原创价值”“转载内容”有明确要求）。
5. **E-E-A-T 偏弱**：作者为“编辑部”，无可验证的实测与经验；关于本站已扩充（资料维护方式、本站不做什么）。
