# 机场怎么选：五个判断标准与新手注意事项

> 本文是 [VPN梯子指南](https://vpntizi.blog/) 的 GitHub 导读版。34 家机场的套餐资料与完整比较请看官网。

“机场”指提供多节点订阅的代理服务：你买到的是一条订阅链接，导入 Clash、Shadowrocket 等客户端后，就能在多个地区的节点之间切换。机场数量很多，宣传词也差不多，新手比较容易被“节点多”“超低价”吸引。真正决定好不好用的，是下面五点。

## 1. 线路类型

宣传里常见三类：直连、普通中转、专线（IEPL / IPLC）。专线的跨境段不走公网，晚高峰和特殊时期通常更稳，但价格更高、流量更少；直连最便宜，也最容易在晚上变卡。只是查资料、偶尔用 AI，普通中转一般够用；每天开视频会议或追剧，可以优先看专线。

## 2. 晚高峰表现

白天快不代表晚上快。判断稳定性，最可靠的办法是在晚上 8 点到 11 点连续用几天：网页、视频、你常用的 AI 工具都试一遍。一次测速截图只代表那一刻、那一个网络环境，说明不了长期表现。

## 3. 流量规则

先确认三件事：流量是每月重置，还是整个周期共用；有没有 2 倍、3 倍等高倍率节点；不限时流量包用完是否就结束。“年付 1200GB”和“每月 100GB”总量相同，但前者可能几个月就用完。

## 4. 设备数与限速

手机、电脑、平板一起用，或者全家共用时，要看同时在线设备数；看 4K 视频要确认没有限速。

## 5. 运营与售后

机场多是小团队，停运时有发生。看它运营了多久、有没有公开的公告频道和退款规则。第一次购买选月付或最短周期，不要为了折扣一次付很长时间，也不要预充大额余额。

## 一个省钱的小提醒

比较价格时分清三个数：实际付款、折合月价、每GB价格。年付折算出来的“每月几块钱”，往往不是你实际要付的钱。
