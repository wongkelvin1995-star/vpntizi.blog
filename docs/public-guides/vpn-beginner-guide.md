# VPN 和机场有什么区别：节点、流量、订阅基础知识

> 本文是 [VPN梯子指南](https://vpntizi.blog/) 的 GitHub 导读版。完整对比表与价格示例请看官网。

刚开始找“梯子”的人，常会看到 VPN、机场、节点、订阅这些词混在一起。它们的目的相似，都是让你的网络请求先到境外服务器，再由服务器去访问目标网站，但用法和体验差别很大。

## VPN 与机场

- **传统 VPN**：一条覆盖整台设备的加密隧道。下载官方 App，登录后一键连接，适合不想折腾的人。
- **机场**：卖的是多节点订阅。你拿到一条订阅链接，导入 Clash、Shadowrocket 等第三方客户端使用；可以按规则分流，让国内网站直连、只有境外网站走代理。

人在国内长期使用，多数人选机场，价格更低、节点更多；短期来华或只为隐私保护，正规 VPN 更省事。

## 节点

节点就是一台中转服务器，通常按地区命名，例如香港、日本、新加坡、美国。不同地区适合不同用途：香港延迟最低，但 ChatGPT 等 AI 服务不对香港开放；日本、新加坡、台湾常用来做 AI 节点；美国服务最全，但延迟较高。

客户端里的延迟数字只反映“请求一来一回的时间”，和视频清晰度（带宽）、晚上会不会断线（稳定性）是三件不同的事。

## 流量

只查资料和用 AI，每月 15–30GB 一般够用；视频是流量大头，1080p 约每小时 3GB，4K 约每小时 7GB。估算后再加两成余量，并留意 2 倍率节点会加倍扣流量。

## 订阅

订阅链接相当于账号凭证。不同客户端要用对应格式：Clash 系客户端用 Clash 订阅，v2rayN、v2rayNG 用通用订阅。链接泄露了，别人就能用你的流量，要尽快在机场后台重置。

## 安全与法律

不同国家和地区对国际联网与代理工具的规定不同，使用前先了解所在地法律法规。客户端只从官方渠道下载，首次购买选短周期。
